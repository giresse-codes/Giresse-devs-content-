# Baddies Airlines (TikTok 1080×1920 · 30 fps · 18.1 s)

Final file: `output/baddies_airlines.mp4`

Style copied from the HusniXD reference (clean Apple-like UI: search bar, cursor, profile cards with chips, blue message bubble, dark/light/purple moments), adapted to the "Baddies" sound:
- Hook: caption pill "POV : t'as des baddies dans chaque pays 🌍", blue shapes merge into a search bar typing "baddies near me".
- Bélgica / Holanda / França / España become Apple-Wallet boarding passes that stack, get a passport stamp on every "(ey)", with a plane flying between destinations.
- Keke 🇨🇩 / Yasmina 🇲🇦 / Beyza 🇹🇷 become contact cards; the cursor books a flight for each.
- Twist on "maar ik ben malaisien": purple flash, spinning 🇲🇾.
- Ends on the next lyric as a typing iMessage bubble — loops back to the start.
- Lyrics: Apple-Music style karaoke (active line, word-by-word highlight, blurred upcoming lines).

Rebuild: `./build.sh <sound-video.mp4> <work-dir> [out.mp4]`
